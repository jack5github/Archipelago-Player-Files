# Refunct Custom Maps

The `maps/` folder within this folder contains a collection of custom maps for Refunct that have been tested and proven to be possible and fun without glitches. All are sourced from the [Refunct Discord server](https://discord.gg/refunct), and if edited, end with `-edit`.

## Usage

In Refunct, press `Ctrl+Shift+M` and select `Open Maps Folder`. Copy the contents of `maps/` into the opened folder. You may also copy `Refunct_Organised (FIXED)` into the same folder and use it as a base for creating new levels, but you must remember to remove it before starting a run (for when random map selection becomes a YAML option).

## Notes

- These maps were last updated on 2026-08-23. Maps uploaded past this date should be considered for inclusion.
- `olivia_puzzle_1` was impossible because its final button was boxed in. The top platform of said box has been lowered into the ground.
- `real_map` was impossible due to several buttons being placed in areas that were inaccessible with ledge grabs. Platforms in their vicinity have been raised (and in one case also moved) to the side to make them accessible.
- `true_waterless`
  - This level was impossible due to several buttons being placed in areas that were inaccessible with wall jumps and ledge grabs. Platforms in their vicinity have been raised or moved to the side to make them accessible.
  - When starting this level, it is possible to fall through the starting platform into the water. Repeatedly start a new game and try various movements until you find your footing.
